# 🏥 PulseCare | منصة الرعاية الصحية الرقمية المتكاملة

> **PulseCare** هي منصة طبية حديثة ومتكاملة مصممة لتقديم تجربة حجز مواعيد سلسة وسريعة للمرضى، مدعومة بلوحة تحكم تفاعلية ومحمية لإدارة أطقم الاستقبال.

---

## ✨ المميزات الرئيسية (Key Features)

* **🩺 واجهة مرضى فاخرة:** تصميم عصري (Glassmorphic & Responsive) متوافق بالكامل مع الهواتف والأجهزة المكتبية.
* **📅 حجز مواعيد مباشر:** استمارة حجز تفاعلية ترتبط فوراً بقاعدة البيانات وتدعم اختيار التخصصات المختلفة.
* **🔐 لوحة تحكم استقبال محمية (`/admin`):**
  * محمية لنظام الأمان بكلمة سر خاصة (`123`).
  * عرض حي وتفاعلي لجميع المواعيد المحجوزة.
  * إحصائيات سريعة للقيادات (إجمالي المواعيد، حالة النظام).
  * خيارات بحث وتصفية فورية وسريعة بحسب اسم المريض، الجوال، أو التخصص.
  * إمكانية إدارة وحذف المواعيد المكتملة.

---

## 🛠️ التقنيات المستخدمة (Tech Stack)

| التقنية | الاستخدام |
| :--- | :--- |
| **Next.js 14+ (App Router)** | إطار العمل الرئيسي لبناء واجهات وسيرفر المشروع |
| **TypeScript** | لضمان جودة الكود وبنائه بشكل منظم |
| **Tailwind CSS** | للتصميم وتنسيق الواجهات العصرية والفاخرة |
| **Lucide React** | الأيقونات التفاعلية والبصرية |
| **MockAPI** | قاعدة بيانات سحابية لإدارة الحجوزات وربط الـ REST API |
| **Vercel & GitHub** | النشر السحابي والاستضافة المباشرة |
